## 🎅 这是什么？

圣诞彩灯 是一款 Android 应用，把你的手机变成圣诞装饰。**重点是手机背景上的彩灯**：
一串绕着屏幕边缘的灯，在主屏幕上同样保持显示。其余的一切都是额外功能。

**核心功能**

- 一串**沿着屏幕边缘的彩灯**，同样显示在主屏幕、图标、小组件和其他应用之上，拥有 5 种效果、5 种配色，可通过快捷设置磁贴开关，重启后自动恢复，并且（可选）会对声音作出反应；

**额外功能**

- **19 棵圣诞树**（14 棵绘制、5 棵照片），外加你的**自己的照片**，可以亲自在上面挂灯；
- **12 个壁炉**，配有真实的粒子火焰，或噼啪作响的炉火照片；
- **9 个互动场景**：雪花球、降临节日历、降临节花环、带火车的圣诞村庄、雪橇、雪人、溜冰场、马槽场景和礼物；
- **场景编辑器**：自己的背景（也可用自己的照片）、自选颜色的火焰、雪、烟花、带自定义动画的贴纸、手绘的灯串，还可以与他人分享；
- **8 种灯**、**3 个小组件**、**动态壁纸**、**4 首圣诞歌曲**、睡眠定时器和收藏的外观；
- **特殊日子**的惊喜（圣尼古拉斯节、平安夜、除夕、主显节……）；
- **6 种语言**：荷兰语、英语、德语、法语、西班牙语和中文。

一切都在应用内部绘制和合成（Canvas，没有游戏引擎，没有 AndroidX）。唯一的
图片是来自维基共享资源的真实圣诞树和壁炉照片（[来源](#-来源与许可)）。
**没有广告，没有账号**。只有当你自己点击*检查更新*时才会使用网络。

## 🚀 首次使用

1. **打开应用。** 你会看到边缘彩灯的设置界面：效果、颜色、速度、亮度、外观和贴合度。
2. **点击“开启彩灯”。** 应用会一次性请求*在其他应用上层显示*的权限。请开启。
   然后返回：彩灯现在会沿着屏幕边缘运行，即使你回到主屏幕也一样。
3. **点击“🎄 打造你的圣诞树”**，打开圣诞树、壁炉和场景视图。向左或向右滑动，在圣诞树、壁炉和场景之间切换。
4. **点击圣诞树**挂上一盏灯。点击一盏灯可更改颜色。长按一盏灯可将其删除。
5. **打开 ⋯ 菜单**，可设置声音、音乐、小组件、收藏、睡眠定时器、语言等。

## ✨ 功能

### 💡 屏幕边缘的彩灯

一串带动画的彩灯沿着屏幕的边缘和圆角运行。触摸会直接穿透
到下面的应用，所以不会碍事。

| 设置 | 选项 |
|---|---|
| **效果** | 常亮、闪烁、交替闪烁、流水灯、彩色波浪和*随音乐* |
| **颜色** | 5 种配色 |
| **速度** | 从慢到快 |
| **亮度** | 30% 到 100% |
| **外观** | 灯的大小、灯与灯的间距和电线的下垂程度 |
| **贴合度** | 圆角弧度和与边缘的距离，使其适合你的屏幕 |

- **位于一切之上。** 彩灯显示在主屏幕、图标、小组件和其他应用之上。
- **开与关。** 通过应用内的按钮、通过 ⋯ 菜单（*屏幕周围的彩灯*）或通过通知栏里的**快捷设置磁贴**。
- **重启之后。** 如果你关机时彩灯是开着的，它们会自动恢复。前提是在其他应用上层显示的权限仍然开启。
- **随麦克风。** 在 ⋯ 菜单中开启*边缘彩灯对声音作出反应*（或选择效果*随音乐*）。声音越大，亮起的灯越多。安静时灯光柔和地亮着。此时应用会请求麦克风权限。参见[权限与隐私](#-权限与隐私)。
- **前台通知。** 只要彩灯开着，Android 就会显示一条通知。这是 Android 对在后台运行的应用的要求。

### 🌲 圣诞树

19 棵圣诞树可以滑动切换，每棵都有自己的装饰，外加你自己的照片。

- **14 棵绘制的树：** 从经典款和松树到霓虹、冰雪和卡通 3D。
- **5 棵真实圣诞树照片：** 国会大厦、室内树、公园里的云杉、城市树和灯饰树。
- **你自己的照片：** 选一张你自己的圣诞树或房间的照片，在上面挂灯。这也可以用作壁纸。
- **每棵树都记得自己的灯。** 切换到另一棵树再切回来，灯仍然挂在原来的位置。
- **每棵树可单独设置灯的类型**，或所有类型混合。

### 🔥 壁炉

12 个带真实火焰的壁炉。7 个绘制的壁炉使用数百个发光粒子。5 个照片壁炉
使用一张照片，上面叠加会动的火焰。点击火焰，它就会腾起。你自己的
灯串挂在壁炉架上或立柱之间。

### ✨ 互动场景

不只是看：点一点、摇一摇、动手搭建。

| 场景 | 怎么玩？ |
|---|---|
| **雪花球** | 摇晃手机或点击：开始下雪。 |
| **降临节日历** | 每天一扇小门，里面有惊喜。 |
| **降临节花环** | 点亮蜡烛，一个星期天接一个星期天。 |
| **带火车的圣诞村庄** | 点击房子亮灯，点击火车鸣笛。长按铁轨让火车停下。点击天空出现一颗小星星。 |
| **圣诞老人的雪橇** | 点击雪橇，礼物像下雨一样落下。长按可以飙速。 |
| **堆雪人** | 点击一下，雪人一步步出现。 |
| **溜冰场** | 点击冰面出现新的溜冰者。溜冰者会互相绕圈。点击一位溜冰者，他会摔倒并滑出冰面。 |
| **马槽场景** | 点击星空许愿。点击玛利亚、约瑟、三王、公牛或驴子，它们会说话。 |
| **礼物** | 你自己的留言，只能在选定的那天打开。 |

### 🎨 制作你自己的场景

你可以完全按自己的想法搭建自己的圣诞场景。打开 **⋯ → 🎨 制作自己的场景**。顶部
可以看到场景之后的实际效果，底部有五个标签页。

| 标签页 | 可以做什么？ |
|---|---|
| 🖼️ **背景** | 从八种渐变色中选择，或使用你**自己的照片**。可开启或关闭雪地。 |
| ✨ **效果** | 雪、下落的东西（礼物、星星、爱心……）、彩纸、闪烁的星星、烟花、流星、柔和的光晕和**火焰**。每种效果都有自己的滑块（数量、速度、大小）和颜色。 |
| 🎅 **贴纸** | 32 张图片（圣诞树、圣诞老人、雪人、雪橇、火车……）。可以拖动、放大或缩小以及旋转。 |
| 💡 **彩灯** | **用手指画一串灯**，沿着窗户、屋顶或树，或选择*顶部*、*弧形*或*四周*。可为每一串灯选择灯的类型、颜色和效果。 |
| 💾 **更多** | 名称、新建场景、复制、你的所有场景、**分享**、粘贴和删除。 |

**自选颜色的火焰。** 把火焰放在你想要的位置，选择橙色、蓝色、绿色、紫色或白色。设置高度、
宽度和速度。在场景中点击火焰，它就会腾起。

**自己的动画。** 每张贴纸都有一个动画和一个对点击的反应：

| 动画 | 点击时的反应 |
|---|---|
| 静止、漂浮、挥动、脉动、闪烁、蹦跳、旋转、驶过、绕圈 | 无、蹦跳、火花、旋转、小铃铛或**说话**（带你自己文字的对话气泡） |

**保存与使用。** 一切都会自动保存。你会在场景列表中找到名为**我的场景**的场景（排在
场景列表的最后）。你可以把它设为**动态壁纸**，也可以收藏。你可以
保存多个场景，并通过*更多 → 我的场景*在它们之间切换。

**分享。** 选择*更多 → 分享*，通过 WhatsApp、电子邮件或其他应用发送文字。接收者复制
这段文字，并在编辑器中选择*更多 → 粘贴*。用作背景的自己的照片不会一起发送。

### 💡 灯的类型

在树的下方，可以从八种类型中选择，或选择一切的**混合**。你可以按每棵树或每个壁炉保存选择，
也可以对所有内容生效，包括你的壁纸。

经典 · 迷你 LED · 玻璃球 · 小火苗 · 小星星 · 爱心 · 冰柱 · 雪花

### 📱 小组件

主屏幕上的三个小组件。长按主屏幕上的空白处，选择*小组件*，找到 *圣诞彩灯*。

| 小组件 | 你会看到什么？ |
|---|---|
| **圣诞倒计时** | 距离圣诞节的天数，节日当天会显示一段文字。 |
| **今日场景** | 与今天日期相符的场景（降临节、马槽、礼物……）。点击后应用会打开该场景。 |
| **带彩灯的圣诞树** | 你自己的树和你的灯，带圆角。点击打开应用。 |

树小组件只在你的树真正发生变化时才刷新，因此不会消耗你的电量。

### 🖼️ 动态壁纸

在应用中选择一棵树、一个壁炉或一个场景，把它设为**动态壁纸**。每次你回到
主屏幕，就能看到例如火焰或行驶的火车，上面还有你的灯。

1. 在应用中选择你想要的树、壁炉或场景。
2. 点击树下方的**壁纸**按钮。
3. 在 Android 的界面中确认。

### 🔊 声音、音乐和麦克风

所有声音都是**在应用内部合成的**。没有音频文件。

- **壁炉火声：** 壁炉旁噼啪作响的火声。
- 点击时有**铃铛声**，场景里有**八音盒旋律**。
- **四首圣诞歌曲：** *Jingle Bells*、*平安夜*、*We wish you a merry Christmas* 和 *Deck the halls*，每首都有自己的速度、八音盒音色和轻微的回声。通过 ⋯ 菜单中的*音乐*选择歌曲。
- **随音乐：** 一种彩灯效果，灯会随着声音而动。它既跟随内置歌曲，也跟随麦克风。

## 🔐 权限与隐私

应用**只有**在你点击 ⋯ 菜单中的*检查更新*时才会使用网络。此时它向 GitHub 查询最新版本的名称，不会发送任何与你有关的信息。除此之外应用不会发送任何东西。一切都留在你的手机上。

| 权限 | 用途 | 是否必需？ |
|---|---|---|
| 在其他应用上层显示（`SYSTEM_ALERT_WINDOW`） | 在主屏幕和其他应用之上显示边缘彩灯 | 仅边缘彩灯需要 |
| 前台服务（`FOREGROUND_SERVICE`、`…_SPECIAL_USE`） | 让边缘彩灯在后台运行 | 仅边缘彩灯需要 |
| 麦克风（`RECORD_AUDIO`、`FOREGROUND_SERVICE_MICROPHONE`） | 对声音作出反应的彩灯 | 否，仅在你选择该效果时 |
| 网络（`INTERNET`） | 仅用于 ⋯ 菜单中的更新检查 | 否，仅在你点击时 |
| 使用情况数据（`PACKAGE_USAGE_STATS`） | 仅用于“仅在主屏幕显示”选项：了解哪个应用在前台 | 是，需要你在系统设置中授予；不会被存储或发送 |
| 通知（`POST_NOTIFICATIONS`） | 每日通知和前台服务的通知 | 否 |
| 开机（`RECEIVE_BOOT_COMPLETED`） | 重启后恢复边缘彩灯和通知 | 否 |

- **麦克风：** 应用只测量声音的大小，用来让彩灯跟着动。不会录音、存储或发送任何内容。只要麦克风在使用，Android 自己会显示麦克风指示。
- **照片：** 你自己的照片只在应用本地使用。
- **数据：** 设置、灯和收藏都保存在应用自己的存储中（`SharedPreferences`）。如果你删除应用，它们就没了。

## 🔋 电量与性能

- 应用使用 Canvas 绘制。静态部分（树）只在位图中保存一次。
- **帧率：** 正常 30 fps，*省电* 15 fps，*自动*会在开启省电模式或电量低于 20% 时切换为 15 fps。
- **在后台**，应用不可见时不会绘制任何内容。*常亮*的边缘彩灯保持静止，不消耗帧。
- **小组件**只在真正有变化时才刷新。
- **麦克风**会额外消耗电量。所以默认是关闭的。
- 在模拟器上，经过最近的优化，帧构建时间的中位数从大约 30 毫秒降到约 23 毫秒。尚未在真实手机上做过测量。

## ❓ 常见问题

**彩灯过一会儿就消失了。**
某些手机品牌（小米、华为、三星、一加……）会强力关闭后台应用。请在
电池设置中为 圣诞彩灯 关闭*电池优化*，并允许*自动启动*。

**我在主屏幕上看不到彩灯。**
请在*设置 → 应用 → 圣诞彩灯 → 在其他应用上层显示*中检查权限是否开启。

**重启后彩灯没有恢复。**
应用必须仍然拥有在其他应用上层显示的权限，并且彩灯必须在重启
之前是开着的。某些厂商会屏蔽开机接收器；请允许*自动启动*。

**小组件什么都不显示或是空的。**
删除小组件并重新添加。树小组件需要应用至少打开过一次。

**安装失败（“应用未安装”）。**
如果已经安装了签名不同的版本，请先卸载它。也请检查你的手机
是否为 Android 8.0 或更高版本。

**应用不联网也能用吗？**
可以，完全可以。网络只用于你自己发起的更新检查。

**可以在 Play 商店下载这个应用吗？**
暂时不行。APK 是供自己安装的。

## 🛠️ 从源码构建

### 要求

- JDK 17
- Android SDK（平台 34/35 和 build-tools；已设置 `ANDROID_HOME`）
- 不需要 Android Studio：Gradle wrapper 会完成一切

### 调试构建与测试

```bash
cd Kerstlampjes
./gradlew testDebugUnitTest assembleDebug
```

APK 位于 `Kerstlampjes/app/build/outputs/apk/debug/app-debug.apk`。

安装到设备或模拟器：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### 发行版（已签名）

1. 创建 keystore：

   ```bash
   keytool -genkeypair -keystore release.keystore -alias kerstlampjes -keyalg RSA -keysize 2048 -validity 10000
   ```
2. 创建 `Kerstlampjes/keystore.properties`（已在 `.gitignore` 中）：

   ```
   storeFile=release.keystore
   storePassword=...
   keyAlias=kerstlampjes
   keyPassword=...
   ```
3. 构建发行版：

   ```bash
   ./gradlew assembleRelease
   ```

   结果：`app/build/outputs/apk/release/app-release.apk`。发行版构建使用 minify 和资源压缩。

请妥善保管 keystore：没有同一把密钥，你就无法再更新已安装的应用。
keystore 和密码**不应**放进 git。

### 在 GitHub 上发布 release

```bash
gh release create v2.4 app-release.apk --title "Kerstlampjes 2.4" --notes "..."
```

## 🧩 技术

- **语言与平台：** Kotlin，`minSdk 26`，不使用 AndroidX。全部是普通的 Android SDK。
- **绘制：** 一个共享的 `TreeRenderer` 同时为树界面、小组件和动态壁纸绘制。
  `SceneHost` 管理场景，`HearthPainter` 管理壁炉。
- **边缘彩灯：** 前台服务中的一个 `TYPE_APPLICATION_OVERLAY` 窗口（`specialUse`，音乐效果开启时再加上 `microphone`）。该窗口不可触摸，所以触摸会穿透。
- **小组件：** 使用 `RemoteViews` 的 `AppWidgetProvider`。树小组件渲染一张位图并缩放它。
- **存储：** 名为 `kerstlampjes` 的 `SharedPreferences`。每棵树的灯保存在以树名为键的条目下，这样以后树的顺序改变也不会丢失你的灯。
- **声音：** 歌曲和效果均为合成；`AudioLevel` 结合麦克风和合成器。只有当某个部分（应用、壁纸或边缘彩灯）需要时，才会打开麦克风。
- **翻译：** 荷兰语文本即键（`Tr.t("…")`、`Tr.f(fmt, …)`）。`Translations.kt` 包含其他五种语言。
- **性能：** 树图层缓存、着色器和路径复用、后台不绘制、`Perf.frameDelay` 用于 30/15 fps。
- **发行：** 用 `proguard-rules.pro` 进行 minify 和 shrink，签名来自 `keystore.properties`。

### 翻译

文本在代码中以荷兰语键的形式存在（`Tr.t("…")`）。翻译在 `Translations.kt` 中。
如果你添加新文本，请填写五种翻译。`TranslationsTest` 测试会检查
所有内容是否已在所有语言中翻译，以及占位符（`%d`、`%s`）是否一致。

## 🎁 屏幕边缘的装饰

除了彩灯，你还可以在主界面的**装饰**里添加很多内容，每一项都可以单独开关：

- 🚂 **小火车**绕圈行驶：俯视时沿着屏幕边缘，侧视时沿着底部边缘。1 到 8 节车厢装满礼物，可选带彩灯。点一下火车它就会鸣笛。
- ❄️ **雪花和小星星**、⭐ **流星**（点一颗就会放烟花）和 🎆 **烟花**（点任意位置听一声巨响）。
- ☃️ **积雪**留在底部边缘。摇晃手机，雪就会飞走，然后重新慢慢堆起来。
- 🧊 **冰柱**挂在顶部边缘。点一下就会掉落，之后又会重新长出来。
- 🎄 **花环**沿着边缘，可选带彩球、可选带彩灯（*显示彩灯*）。
- 🛷 **驯鹿雪橇**、🐧 **企鹅和雪人**（点一下它们会跳起来）和显示你自定义文字的**滚动字幕**。
- **仅在主屏幕显示：** 可以让这些内容不出现在其他应用上方。为此应用需要访问使用情况数据，以便知道哪个应用在前台。数据只保留在手机上，不会被存储或发送。

点击需要在游戏界面（**🎮 玩转屏幕边缘**）中进行。其他应用上方的悬浮层会让所有点击穿透到下面的应用，但摇晃在任何地方都有效。
